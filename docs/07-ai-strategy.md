# AI Integration Strategy

AI is not the source of truth.

## Correct Boundary

```text
LLM suggests or explains.
Backend validates.
Learning engine decides.
Database stores truth.
```

## Useful AI Features Later

- generate hints;
- rewrite explanations for the user's level;
- evaluate free-text answers against a rubric;
- summarize mistakes;
- assist with project feedback.

## Not Delegated To AI

- final database updates;
- skill taxonomy ownership;
- progression decisions;
- prerequisite rules;
- silent roadmap changes.

## Validation

AI responses should use structured schemas and should be logged for review.
