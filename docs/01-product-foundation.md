# Product Foundation

## Target User

Beginner or early-junior developers who want to become Python backend developers
and need guidance, practice, feedback, and adaptive next steps.

## Core Problem

Learners often have access to content but do not know:

- what they actually understand;
- what they should practice next;
- whether they are ready to move forward;
- how their weak skills affect real project work.

## Core Promise

The platform estimates user skill mastery and recommends the next best learning
activity.

## MVP Loop

```text
Choose goal
-> diagnostic / first exercise
-> learning path
-> topic
-> exercise
-> evaluation
-> knowledge update
-> recommendation
```

## MVP Non-Goals

- No microservices.
- No complex ML.
- No vector database.
- No mobile app.
- No gamification.
- No social features.
- No fully AI-generated curriculum.
